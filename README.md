# 汇率找零 · 多币种收付与找零计算器

一个轻量的多币种结算工具：**纯前端、无服务器、可离线、能装到手机桌面。**

---

## 用途

处理「付款和找零涉及多种货币」的场景。比如一笔应收是 10 美元，对方给的是 10 美元加一部分日元，需要快速得出：该找多少、找哪几种币、能不能凑整。

工具直接给出组合结果，例如「找 5 美元 + 750 日元」。

适用于多币种流通地区的小额结算、跨境旅行、外币零售等场合。

## 功能

- **16 种货币**：美元、人民币、日元、欧元、英镑、韩元、泰铢、柬埔寨瑞尔、越南盾、港币、新加坡元、澳元、加元、瑞士法郎、马来西亚令吉、印度卢比
- **应付金额支持多币种相加** —— 如 `10 USD + 1500 JPY` 可直接录入
- **付款支持多币种分别填写** —— 每种货币给多少就记多少
- **找零币种可增删** —— 可按需排除不收的币种
- **锁定一种、自动算其余** —— 手动指定某币种找零金额，剩余自动折算补足
- **最优找零** —— 跨币种按面额搭配，尽量减少硬币数量
- **内置计算器** —— 计算结果可一键填入应付金额，并跟随当前选中的输入行
- **汇率联网更新 + 本地缓存** —— 离线时沿用最近一次汇率
- **自动记住界面状态** —— 币种、开关、输入内容下次打开原样恢复，另有「重置界面」按钮

## 安装到手机

1. 用手机浏览器打开上方网址
2. Chrome / Edge：右上角「⋮」→「添加到主屏幕」/「安装应用」
3. 之后通过桌面图标全屏启动

## 数据与隐私

**全部数据保存在浏览器本地。** 汇率存于 localStorage，所有计算在客户端完成，不上传任何信息到服务器。部署的网址只是一份静态页面，无法获取使用者的输入内容。

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，无框架、无构建步骤
- `change-core.js`：核心计算模块（汇率换算、找零拆分、跨币种最优找零），浏览器与 Node 环境通用
- 以 USD 为基准币，汇率统一存为「1 单位该币 = X USD」，避免多头换算的精度损失
- 各币种小数位分别处理（KHR / VND / JPY / KRW 为 0 位）
- `sw.js`：Service Worker 离线缓存，页面采用「网络优先 + 超时回退缓存」策略，兼顾启动速度与版本更新
- 汇率数据来源：[open.er-api.com](https://open.er-api.com)，免密钥、支持 CORS
